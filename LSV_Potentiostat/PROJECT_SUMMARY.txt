TECHNICAL SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════

Hardware Platform:    ESP32 Development Board (3.3V logic)
Microcontroller:      ESP32 (Dual-core, 240MHz, 520KB RAM)

Voltage Control:      MCP4725 12-bit DAC → LM358 Op-Amp Potentiostat
  • Voltage Range:    0V to 1.2V (configurable -1V to +1.5V)
  • Resolution:       0.8mV steps (12-bit)
  • Control Method:   Feedback-controlled 3-electrode cell

Current Measurement:  ADS1115 16-bit ADC → Transimpedance Amplifier
  • Current Range:    ±100µA typical (±2mA maximum)
  • Resolution:       0.625nA per bit
  • Sensitivity:      100kΩ feedback resistor

Electrochemical Cell:
  • Configuration:    3-electrode (Working, Reference, Counter)
  • Technique:        Linear Sweep Voltammetry (LSV)
  • Electrolyte:      0.1M KCl or 0.5M H₂SO₄
  • Scan Speed:       10mV/step, 80ms settle time

Detection Capability:
  • Copper (Cu):      Peak at 0.0-0.2V vs Cu reference
  • Silver (Ag):      Peak at 0.3-0.5V vs Cu reference
  • Nickel (Ni):      Peak at -0.1-0.1V (extended scan)
  • Zinc (Zn):        Peak at -0.8 to -0.6V (extended scan)

Karat Classification:
  • 24K (99.9% Au):   No peaks (<0.5µA)
  • 22K (91.6% Au):   Small peaks (0.5-2.0µA)
  • 18K (75.0% Au):   Medium peaks (2.0-5.0µA)
  • 14K (58.3% Au):   Large peaks (>5.0µA)

Scan Performance:
  • Scan Time:        15-30 seconds per sample
  • Data Points:      120-300 points per scan
  • Auto-repeat:      Every 30 seconds (configurable)

USAGE INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════

Quick Start (30 minutes):
  1. Assemble circuit on breadboard (see QUICK_START.md)
  2. Install Arduino IDE + ESP32 board support
  3. Install libraries: Adafruit_ADS1X15, Adafruit_MCP4725
  4. Open LSV_Potentiostat.ino and upload to ESP32
  5. Open Serial Monitor at 115200 baud
  6. Prepare electrolyte (salt water or 0.1M KCl)
  7. Run copper wire test (verify circuit works)
  8. Test gold sample (attach as working electrode)

Calibration (1-2 hours):
  1. Obtain known gold standards (14K, 18K, 22K, 24K)
  2. Run 3 scans on each standard sample
  3. Record peak heights for Cu and Ag
  4. Update threshold values in include/config.h
  5. Re-upload firmware with new calibration
  6. Validate with unknown sample

Customization:
  • Scan parameters:      Edit include/config.h
  • Peak detection:       Edit src/peak_analysis.cpp
  • Karat thresholds:     Edit include/config.h or src/karat_estimation.cpp
  • Hardware pins:        Edit include/config.h
