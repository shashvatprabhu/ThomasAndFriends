📂 PROJECT ROOT
═══════════════════════════════════════════════════════════════════════════

📄 LSV_Potentiostat.ino
   ├─ PURPOSE: Main Arduino sketch (START HERE!)
   ├─ CONTAINS: setup() and loop() functions
   ├─ WHEN TO EDIT: Almost never (high-level orchestration only)
   └─ UPLOAD THIS: Yes - this is what you upload to ESP32

📄 platformio.ini
   ├─ PURPOSE: PlatformIO project configuration (optional)
   ├─ CONTAINS: Build settings, library dependencies
   ├─ WHEN TO EDIT: Only if using PlatformIO instead of Arduino IDE
   └─ UPLOAD THIS: No (build configuration only)

═══════════════════════════════════════════════════════════════════════════
📂 include/ - HEADER FILES (Declarations)
═══════════════════════════════════════════════════════════════════════════

📄 include/config.h ⭐ MOST IMPORTANT FOR CUSTOMIZATION
   ├─ PURPOSE: All tunable parameters in one place
   ├─ CONTAINS:
   │  • I2C pin definitions (GPIO21, GPIO22)
   │  • Scan parameters (voltage range, step size, timing)
   │  • Calibration constants (resistor values, thresholds)
   │  • Peak detection windows (Cu: 0.0-0.25V, Ag: 0.3-0.55V)
   │  • Feature flags (enable/disable smoothing, CSV export, etc.)
   ├─ WHEN TO EDIT:
   │  • ✅ Adjust scan speed (STEP_SIZE, SETTLE_TIME_MS)
   │  • ✅ Change voltage range (START_VOLTAGE, END_VOLTAGE)
   │  • ✅ Update calibration thresholds after testing known samples
   │  • ✅ Enable/disable advanced features
   └─ EXAMPLE CHANGES:
      • Faster scan: STEP_SIZE = 0.02, SETTLE_TIME_MS = 50
      • Wider range: START_VOLTAGE = -0.5, END_VOLTAGE = 1.5
      • After calibration: KARAT_24_MAX = 0.6, KARAT_22_MAX = 2.5

📄 include/lsv_scan.h
   ├─ PURPOSE: Declarations for LSV scanning functions
   ├─ CONTAINS: Function prototypes, LSVData structure definition
   ├─ WHEN TO EDIT: Rarely (only if adding new scan functions)
   └─ PAIRS WITH: src/lsv_scan.cpp

📄 include/peak_analysis.h
   ├─ PURPOSE: Declarations for peak detection functions
   ├─ CONTAINS: PeakInfo and PeakAnalysisResult structures
   ├─ WHEN TO EDIT: Rarely (only if adding new analysis methods)
   └─ PAIRS WITH: src/peak_analysis.cpp

📄 include/karat_estimation.h
   ├─ PURPOSE: Declarations for karat estimation functions
   ├─ CONTAINS: KaratEstimate structure, karat conversion functions
   ├─ WHEN TO EDIT: Rarely (only if changing estimation algorithm)
   └─ PAIRS WITH: src/karat_estimation.cpp

═══════════════════════════════════════════════════════════════════════════
📂 src/ - SOURCE FILES (Implementations)
═══════════════════════════════════════════════════════════════════════════

📄 src/lsv_scan.cpp
   ├─ PURPOSE: Core electrochemical scanning functionality
   ├─ CONTAINS:
   │  • initializeHardware() - Setup I2C, DAC, ADC
   │  • performLSVScan() - Voltage sweep and current measurement
   │  • setDACVoltage() - Control applied voltage
   │  • readCurrent() - Measure current via ADC
   │  • measureBaseline() - Record baseline offset
   ├─ WHEN TO EDIT:
   │  • Change hardware initialization sequence
   │  • Modify scan algorithm (e.g., add reverse scan)
   │  • Improve current measurement (filtering, averaging)
   └─ TYPICAL EDITS: Advanced users only

📄 src/peak_analysis.cpp
   ├─ PURPOSE: Extract oxidation peaks from scan data
   ├─ CONTAINS:
   │  • analyzePeaks() - Main analysis routine
   │  • findPeakInRange() - Detect peak in voltage window
   │  • calculatePeakArea() - Integrate peak area
   │  • applySmoothingFilter() - Noise reduction
   ├─ WHEN TO EDIT:
   │  • ✅ Improve peak detection algorithm
   │  • ✅ Add Gaussian peak fitting
   │  • ✅ Change smoothing filter parameters
   └─ TYPICAL EDITS: If peaks are not detected correctly

📄 src/karat_estimation.cpp
   ├─ PURPOSE: Estimate gold purity from peak data
   ├─ CONTAINS:
   │  • estimateKarat() - Main estimation routine
   │  • classifyByTotalPeak() - Threshold-based method
   │  • classifyByMetalRatio() - Ratio-based method
   │  • calculateConfidence() - Reliability metric
   ├─ WHEN TO EDIT:
   │  • ✅ Update classification thresholds (after calibration)
   │  • ✅ Add machine learning classification
   │  • ✅ Improve confidence calculation
   └─ TYPICAL EDITS: After you calibrate with known samples

🔧 EDITING WORKFLOW
═══════════════════════════════════════════════════════════════════════════

FOR SIMPLE CHANGES (scan parameters, thresholds):

  1. Open: include/config.h in Arduino IDE or text editor
  2. Find: #define for parameter you want to change
  3. Edit: Change the value (e.g., STEP_SIZE from 0.01 to 0.02)
  4. Save: File → Save
  5. Upload: Click Upload button (→) in Arduino IDE
  6. Test: Open Serial Monitor and run scan

FOR ADVANCED CHANGES (algorithms, new features):

  1. Open: Appropriate .cpp file (lsv_scan.cpp, peak_analysis.cpp, etc.)
  2. Edit: Modify function implementation
  3. Save: File → Save
  4. Upload: Click Upload button (→) in Arduino IDE
  5. Debug: Watch Serial Monitor for errors
  6. Iterate: Refine until working correctly

FOR DOCUMENTATION UPDATES:

  1. Open: Appropriate .md file in text editor
  2. Edit: Markdown formatting (headings with #, lists with -)
  3. Save: File → Save
  4. View: Use Markdown viewer or GitHub to see formatted version
